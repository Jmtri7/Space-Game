cultures.json → salt_crows — proposed, not in config

  1. Asymmetric and kinked. A bent spine, wider to one side, a heavy pointed ram prow with reinforcement plates. Deliberately lopsided — nothing mirrors.
  2. Three ships' worth of wings. Each wing scavenged from a different culture and bolted on crooked — a tapered Vherathi one, a riveted Drossholt box, a clean Federation panel — in their original colours.
  3. Mismatched everything. Oversized bolted engine housings, one much bigger, both with visible bolt rings and patch plates. Rust streaks, brass patches, trophy trinkets on the rail.
  4. The mark. A crude asymmetric bone-white crow glyph daubed on the hull. It's the only thing that's theirs.

Wiring in

cultures.json

One entry — name, description, the colour keys shown, a theme string, an interior_decoration generator. Self-contained; assets reference it by key.

ship_types.json + graphics.json

One row per hull. Each ship silhouette here is strokeless and can be extracted into parts via extract_atlas.py / apply_parts.py — add a row to the T table.

outfits & the figure renderer

The recoloured base of each outfit is a graphics.json entry. The signature pieces are baked geometry — the same path as the shipped cultures: a signature function in a salt_crows_outfits.py, baked by build_figure_signatures.py into figure_signatures.py, emitted by Person.draw().

system + routine

The Salt Crows want a raider routine — shadow a lane, close on a lone hull, hail once, then board. A culture is half a faction without a system to live in, a pilot roster and an AI routine.

Adding a culture is additive; adding ship types and outfits is not free. A new ship type shows in every shipyard and a new outfit in every outfitter — an old save loading a shop sees the new stock. That's a story-version bump (see SAVE_SYSTEM.md), not a breakage: NPCs and outfits rebuild from story config on load.

Part of Past the Reach — seven proposed frontier cultures. Companion atlases: Common Kit, Sol Federation, Vherathi Concord, Drossholt Company. Same visual system, same strokeless rule, same figure_parts body.
