cultures.json → vetl — proposed, not in config

  1. A creature silhouette. A broad flat manta body — a smooth wide lens, widest at mid, tapering both ways — with forward cephalic horn-prongs and a long tapering whip tail ending in a barb. No panel lines; it isn't panelled.
  2. Bone and hide. A fan of pale rib-veins from the spine to the wing edge, a dorsal ridge of small spines, mottled darker hide patches for texture.
  3. Spirit light. A constellation of teal motes on the back joined by thin lines, two large bio eye-spots near the nose. The exhaust is a soft glow at the tail, not a nozzle.
  4. Worn, not issued. Crew wear antler headdresses, layered hide with a feathered hem, bead-strand necklaces, face paint, and carry a bound staff. No two identical.

Wiring in

cultures.json

One entry — name, description, the colour keys shown, a theme string, an interior_decoration generator. Self-contained; assets reference it by key.

ship_types.json + graphics.json

One row per hull. Each ship silhouette here is strokeless and can be extracted into parts via extract_atlas.py / apply_parts.py — add a row to the T table.

outfits & the figure renderer

The recoloured base of each outfit is a graphics.json entry. The signature pieces are baked geometry — the same path as the shipped cultures: a signature function in a vetl_outfits.py, baked by build_figure_signatures.py into figure_signatures.py, emitted by Person.draw().

system + routine

The Vetl want an explorer / wander routine — drift the deep field, never make port for long. A culture is half a faction without a system to live in, a pilot roster and an AI routine.

Adding a culture is additive; adding ship types and outfits is not free. A new ship type shows in every shipyard and a new outfit in every outfitter — an old save loading a shop sees the new stock. That's a story-version bump (see SAVE_SYSTEM.md), not a breakage: NPCs and outfits rebuild from story config on load.

Part of Past the Reach — seven proposed frontier cultures. Companion atlases: Common Kit, Sol Federation, Vherathi Concord, Drossholt Company. Same visual system, same strokeless rule, same figure_parts body.
