cultures.json → meridian — proposed, not in config

  1. A banded lantern hull. One long tapering hull divided into decks by brass bands, not stacked balls. Symmetric and centred — not the Vherathi organic asymmetry.
  2. Ornament is the point. Brass filigree scrollwork framing the fore hull, a stylised sunburst figurehead prow, a crowning lantern finial — every edge trimmed.
  3. Windows and lanterns on show. An arched row of warm windows per deck plus a lantern pair at each end — a Meridian captain wants to be seen.
  4. Swept sail-fins. Two large decorative fins sweep well aft from mid-hull, scalloped along the trailing edge, brass-ribbed.

Wiring in

cultures.json

One entry — name, description, the colour keys shown, a theme string, an interior_decoration generator. Self-contained; assets reference it by key.

ship_types.json + graphics.json

One row per hull. Each ship silhouette here is strokeless and can be extracted into parts via extract_atlas.py / apply_parts.py — add a row to the T table.

outfits & the figure renderer

The recoloured base of each outfit is a graphics.json entry. The signature pieces are baked geometry — the same path as the shipped cultures: a signature function in a meridian_outfits.py, baked by build_figure_signatures.py into figure_signatures.py, emitted by Person.draw().

system + routine

Meridian wants a trader routine — run a circuit between ports, buy low, sell high, dock in style. A culture is half a faction without a system to live in, a pilot roster and an AI routine.

Adding a culture is additive; adding ship types and outfits is not free. A new ship type shows in every shipyard and a new outfit in every outfitter — an old save loading a shop sees the new stock. That's a story-version bump (see SAVE_SYSTEM.md), not a breakage: NPCs and outfits rebuild from story config on load.

Part of Past the Reach — seven proposed frontier cultures. Companion atlases: Common Kit, Sol Federation, Vherathi Concord, Drossholt Company. Same visual system, same strokeless rule, same figure_parts body.
