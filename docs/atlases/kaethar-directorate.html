cultures.json → kaethar — proposed, not in config

  1. Arrowhead and rail. A sharp narrow nose widening to a blocky midbody, a raised spinal rail its full length to a muzzle at the tip. Every corner a hard angle — no fillet, no curve, anywhere.
  2. Forward-swept everything. Wing pylons, turret nacelles, antenna masts sweep forward, toward the target, not back. Blocky hardpoint pods.
  3. One warning colour. Sharp red chevrons along every leading edge, a hard diamond unit sigil, red rank and sensor bars. The hull stays flat gunmetal — recessed panel seams and nothing else.
  4. Rank and file inside. A straight spine, identical cells, a painted line you walk between. The Standard Issue plan with the warmth removed.

Wiring in

cultures.json

One entry — name, description, the colour keys shown, a theme string, an interior_decoration generator. Self-contained; assets reference it by key.

ship_types.json + graphics.json

One row per hull. Each ship silhouette here is strokeless and can be extracted into parts via extract_atlas.py / apply_parts.py — add a row to the T table.

outfits & the figure renderer

The recoloured base of each outfit is a graphics.json entry. The signature pieces are baked geometry — the same path as the shipped cultures: a signature function in a kaethar_outfits.py, baked by build_figure_signatures.py into figure_signatures.py, emitted by Person.draw().

system + routine

Kaethar wants a patrol / picket routine — hold a lane, challenge every transponder, escalate on a bad reply. A culture is half a faction without a system to live in, a pilot roster and an AI routine.

Adding a culture is additive; adding ship types and outfits is not free. A new ship type shows in every shipyard and a new outfit in every outfitter — an old save loading a shop sees the new stock. That's a story-version bump (see SAVE_SYSTEM.md), not a breakage: NPCs and outfits rebuild from story config on load.

Part of Past the Reach — seven proposed frontier cultures. Companion atlases: Common Kit, Sol Federation, Vherathi Concord, Drossholt Company. Same visual system, same strokeless rule, same figure_parts body.
