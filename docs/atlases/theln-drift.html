cultures.json → theln — proposed, not in config

  1. Membrane on frame. Sail panels stretched over a light exoskeleton of thin struts. Trailing edges ripple — never a straight cut, never a solid hull.
  2. Asymmetric spars. Booms and struts of uneven length; one side always reaches further. A long tail boom trails aft with its own small fin.
  3. Lights on the rigging. Running lights strung in lines along every spar and down the spine.
  4. Sensory tendrils. Thin trailing lines off the nose, tipped with a light — part antenna, part streamer.

Wiring in

cultures.json

One entry — name, description, the colour keys shown, a theme string, an interior_decoration generator. Self-contained; assets reference it by key.

ship_types.json + graphics.json

One row per hull. Each ship silhouette here is strokeless and can be extracted into parts via extract_atlas.py / apply_parts.py — add a row to the T table.

outfits & the figure renderer

The recoloured base of each outfit is a graphics.json entry. The signature pieces are baked geometry — the same path as the shipped cultures: a signature function in a theln_outfits.py, baked by build_figure_signatures.py into figure_signatures.py, emitted by Person.draw().

system + routine

The Theln want a drift routine — slow wandering transits, rarely docking, following the field. A culture is half a faction without a system to live in, a pilot roster and an AI routine.

Adding a culture is additive; adding ship types and outfits is not free. A new ship type shows in every shipyard and a new outfit in every outfitter — an old save loading a shop sees the new stock. That's a story-version bump (see SAVE_SYSTEM.md), not a breakage: NPCs and outfits rebuild from story config on load.

Part of Past the Reach — seven proposed frontier cultures. Companion atlases: Common Kit, Sol Federation, Vherathi Concord, Drossholt Company. Same visual system, same strokeless rule, same figure_parts body.
