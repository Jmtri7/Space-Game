The ember in the stone

A close order that keeps to the burnt worlds. Where the Vherathi grow their hulls and the Drossholt bolt theirs, the Kessari fire theirs — dark ceramic carved like a reliquary, lit only where the material is still cooling.

cultures.json → kessari — proposed, not in config

  1. One carved mass. A tall base-heavy monolith with stepped flying-buttress flanks, recessed relief grooves across the face, and a finial spire cluster at the nose. Roughly symmetric, one edge always left hand-irregular.
  2. The ember seam. A bright ladder of ember light down the spine with cross-ribs, a radial rose-window aperture cluster near the nose, a matching glow through the exhaust. Everything else near-black.
  3. Ceremonial fittings. The exhaust is an ornate perforated censer housing, not a nozzle; buttress edges carry an ash-grey trim line.
  4. Cell, not cabin. Interiors stay narrow, dim, high-contrast: black floor and walls, one bright line of light down the centre of every room.

Wiring in

cultures.json

One entry — name, description, the colour keys shown, a theme string, an interior_decoration generator. Self-contained; assets reference it by key.

ship_types.json + graphics.json

One row per hull. Each ship silhouette here is strokeless and can be extracted into parts via extract_atlas.py / apply_parts.py — add a row to the T table.

outfits & the figure renderer

The recoloured base of each outfit is a graphics.json entry. The signature pieces are baked geometry — the same path as the shipped cultures: a signature function in a kessari_outfits.py, baked by build_figure_signatures.py into figure_signatures.py, emitted by Person.draw().

system + routine

The Kessari want a pilgrimage routine — slow circuits between burnt worlds, never hurrying, never trading. A culture is half a faction without a system to live in, a pilot roster and an AI routine.

Adding a culture is additive; adding ship types and outfits is not free. A new ship type shows in every shipyard and a new outfit in every outfitter — an old save loading a shop sees the new stock. That's a story-version bump (see SAVE_SYSTEM.md), not a breakage: NPCs and outfits rebuild from story config on load.

Part of Past the Reach — seven proposed frontier cultures. Companion atlases: Common Kit, Sol Federation, Vherathi Concord, Drossholt Company. Same visual system, same strokeless rule, same figure_parts body.
