Draw order

The whole story's back-to-front stack: body parts interleaved with garment tags. Reorder anything by its arrows or by dragging the row (this is the only place body-part order can be changed); a region tagged with a name draws at that slot. Fit

Overwrites this article's geometry for the other body on disk with a copy of the cut you're editing now (also saves the current cut). Then switch the body dropdown above to re-fit the copy by hand.
Every garment vertex is a plain free point you can drag and snap onto the body (below). To fill in an edge: snap two vertices onto the body, select both, and generate the body's own points between them — no dropdown, no curve names. Select 2+ that aren't both snapped to free several at once. (A vertex a real garment file already fits to a named curve shows ● purple and won't drag until you clear that — select just it to do so.)
Snapping copies a body vertex's exact position — it's a one-time alignment, not a live fit; if the body reshapes later this vertex won't follow (use the Fit panel's curve dropdown for that).
Body parts — eye = show/hide the part, dot = show/hide just its snap-able vertices (keeps the part visible, less clutter).

attach new pieces to
a region is a standalone garment piece (own group, tag, fits, shade) — it copies the selected region's group and tag if one is selected; set its name, anim. group and draw order tag in the Selected section panel above. A polygon/circle is a detail on the selected region (rides its group, no fit).
dbl-click a handle = select its whole polygon (shift = add). 2+ selected points show a scale handle at each corner; drag one, or use [ ] to scale and , . to rotate about the selection's centre. To insert a vertex, click one end of the edge, shift-click the other end, then press I — reliable even on a tiny, crowded edge where dbl-clicking the line itself is hard to aim (that still works too, once you isolate the piece in the list below to declutter it).

Save / download drafts

Every autosaved draft in this browser, not just the design loaded above - handy after editing several articles/bodies in one sitting. save checked to repo overwrites each draft's real file on disk with your edits (needs the repo folder opened read-write, above; Chrome/Edge from disk). download checked is the fallback everywhere else - rename a row first if two land on the same filename. Reset (above) only drops the one draft for whatever's currently loaded - use "clear checked" here to actually shrink this list.
